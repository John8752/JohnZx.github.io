# John · ZX — Personal site

A small, dependency-free personal website for 正祥 (John), hosted with GitHub Pages.

## Local preview

Open `index.html` directly, or start any static file server in this directory:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` — page content and SEO metadata
- `styles.css` — responsive design and light/dark themes
- `script.js` — theme, navigation, and reveal interactions
- `404.html` — custom not-found page

No build step or third-party dependency is required.
